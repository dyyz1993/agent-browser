# 丰富跨域iframe测试用例计划

## 测试目标
丰富现有的跨域iframe测试用例，特别是快照校验、跨域校验和跨域iframe的点击操作。

## 测试用例设计

### 1. 快照校验增强
- **测试不同快照选项**：测试 `interactive`、`cursor`、`maxDepth`、`compact` 等选项在跨域iframe中的效果
- **测试快照引用**：验证跨域iframe快照中的元素引用是否正确生成和使用
- **测试选择性快照**：测试使用 `selector` 参数在跨域iframe中获取特定元素的快照
- **测试快照对比**：验证在跨域iframe中执行操作前后的快照变化

### 2. 跨域校验增强
- **测试跨域iframe导航**：验证在跨域iframe中执行导航操作的正确性
- **测试跨域iframe属性获取**：验证是否可以正确获取跨域iframe的属性、文本内容等
- **测试跨域iframe事件处理**：验证在跨域iframe中触发事件的处理
- **测试跨域iframe错误处理**：验证当尝试访问跨域iframe的受限内容时的错误处理

### 3. 跨域iframe点击增强
- **测试不同类型元素的点击**：测试按钮、链接、复选框等不同类型元素的点击操作
- **测试点击后的状态变化**：验证点击操作后元素状态的变化（如按钮变为禁用、复选框变为选中）
- **测试点击后的页面导航**：验证点击链接后跨域iframe的导航行为
- **测试双击和右键点击**：测试跨域iframe中的双击和右键点击操作

### 4. 其他增强测试
- **测试嵌套多层跨域iframe**：验证对多层嵌套跨域iframe的操作能力
- **测试跨域iframe的表单提交**：验证在跨域iframe中提交表单的行为
- **测试跨域iframe的文件上传**：验证在跨域iframe中执行文件上传操作
- **测试跨域iframe的滚动操作**：验证在跨域iframe中执行滚动操作

## 实现步骤
1. 分析现有测试文件 `iframe-cross-origin.e2e.test.ts` 的结构和测试用例
2. 按照上述测试目标设计新的测试用例
3. 实现新的测试用例，确保测试覆盖所有设计的场景
4. 运行测试，验证测试用例的正确性
5. 优化测试用例，确保测试的稳定性和可靠性

## 预期结果
- 增加至少10个新的测试用例，覆盖快照校验、跨域校验和跨域iframe点击的各种场景
- 所有测试用例都能正常通过，验证跨域iframe操作的正确性
- 测试用例具有良好的可读性和可维护性，便于后续扩展
