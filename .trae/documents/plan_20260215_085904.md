## 封装 `inFrame` 参数方案

### 1. 修改 `protocol.ts`

在 `baseCommandSchema` 后添加 `withFrame` 工厂函数：

```typescript
// Base schema for all commands
const baseCommandSchema = z.object({
  id: z.string(),
  action: z.string(),
});

// Helper to add inFrame support to element-action schemas
const withFrame = <T extends z.ZodRawShape>(schema: z.ZodObject<T>) => 
  schema.extend({ inFrame: z.string().optional() });
```

### 2. 需要应用 `withFrame` 的 Schema（元素操作类）

| 命令类型 | Schema 名称 |
|---------|-------------|
| 点击操作 | `clickSchema`, `dblclickSchema` |
| 输入操作 | `typeSchema`, `fillSchema` |
| 状态操作 | `checkSchema`, `uncheckSchema`, `focusSchema`, `hoverSchema` |
| 选择操作 | `selectSchema` |
| 快照操作 | `snapshotSchema` |
| 查找操作 | `getByRoleSchema`, `getByTextSchema`, `getByLabelSchema`, `getByPlaceholderSchema`, `getByAltTextSchema`, `getByTitleSchema`, `getByTestIdSchema` |
| 获取操作 | `getAttributeSchema`, `getTextSchema`, `innerTextSchema`, `innerHtmlSchema`, `inputValueSchema` |
| 状态检查 | `isVisibleSchema`, `isEnabledSchema`, `isCheckedSchema`, `countSchema` |
| 其他操作 | `scrollIntoViewSchema`, `highlightSchema`, `dragSchema`, `boundingBoxSchema`, `stylesSchema`, `setValueSchema`, `clearSchema` |

### 3. 修改示例

```typescript
// 修改前
const clickSchema = baseCommandSchema.extend({
  action: z.literal('click'),
  selector: z.string().min(1),
  button: z.enum(['left', 'right', 'middle']).optional(),
  clickCount: z.number().positive().optional(),
  delay: z.number().nonnegative().optional(),
});

// 修改后
const clickSchema = withFrame(baseCommandSchema.extend({
  action: z.literal('click'),
  selector: z.string().min(1),
  button: z.enum(['left', 'right', 'middle']).optional(),
  clickCount: z.number().positive().optional(),
  delay: z.number().nonnegative().optional(),
}));
```

### 4. 不需要 `inFrame` 的 Schema（导航/浏览器级）

`launchSchema`, `navigateSchema`, `backSchema`, `forwardSchema`, `reloadSchema`, `closeSchema`, `tab_*Schema`, `cookies_*Schema`, `storage_*Schema`, `viewportSchema`, `offlineSchema` 等

### 5. 涉及文件

- `src/protocol.ts` - 添加 `withFrame` 函数并应用到相关 schema
- `src/cli.ts` - 无需修改（已正确解析 `--in-frame`）
- `src/actions.ts` - 无需修改（已正确处理 `command.inFrame`）
