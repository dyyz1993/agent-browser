# Agent-Browser 人工交互功能增强计划

## 背景

当前 agent-browser 已经具备：
- `StreamServer`: WebSocket 服务器，支持实时屏幕广播和输入注入
- `startHttpServer`: HTTP 服务器用于接收命令
- `AGENT_BROWSER_STREAM_PORT` 环境变量用于启用流媒体服务
- 流媒体端口存储在 `~/.agent-browser/<session>.stream` 文件中

**缺失的功能**：
1. 没有便捷的方式让用户获取远程查看 URL
2. 没有前端 HTML 页面用于用户实时交互
3. 没有 `ask` 命令用于暂停并询问用户

## 目标

实现两个核心功能：

### 1. `viewer` 命令 - 获取远程交互 URL

让用户能够打开一个网页，实时查看浏览器画面并进行交互操作。

**使用场景**：
- 遇到验证码时，让用户手动解决
- 遇到需要登录的页面，让用户手动登录
- 调试时实时查看自动化过程

### 2. `ask` 命令 - 暂停并询问用户

通过 Message Bridge 推送接口暂停自动化流程，等待用户操作或输入。

**使用场景**：
- 需要用户确认操作
- 需要用户输入敏感信息
- 遇到无法自动处理的情况

### Phase 2: 自适应画质与 Sharp 压缩

#### 2.1 状态定义

| 状态 | 触发条件 | 画质 | FPS | 用途 |
|------|----------|------|-----|------|
| `user_interacting` | 用户操作（鼠标/点击/滚动） | JPEG q10 | 60 | 用户操作时追求流畅 |
| `screen_moving` | 帧间隔 < 1000ms | WebP q50 | 2 | 画面自动变化时节省带宽 |
| `static` | 帧间隔 >= 1000ms | WebP q80 | 0.5 | 静止时传输高质量画面 |

#### 2.2 状态管理 (src/stream-server.ts)

```typescript
type StreamState = 'user_interacting' | 'screen_moving' | 'static';

interface StreamStateConfig {
  format: 'jpeg' | 'webp';
  quality: number;
  fps: number;
}

const STATE_CONFIGS: Record<StreamState, StreamStateConfig> = {
  user_interacting: { format: 'jpeg', quality: 10, fps: 60 },
  screen_moving: { format: 'webp', quality: 50, fps: 2 },
  static: { format: 'webp', quality: 80, fps: 0.5 },
};

class StreamStateManager {
  private currentState: StreamState = 'static';
  private lastFrameTime: number = 0;
  private userInteractionTimeout: NodeJS.Timeout | null = null;
  
  onUserInteraction() {
    this.currentState = 'user_interacting';
    this.resetUserInteractionTimeout();
  }
  
  onFrameReceived() {
    const now = Date.now();
    const interval = now - this.lastFrameTime;
    
    if (this.currentState !== 'user_interacting') {
      this.currentState = interval < 1000 ? 'screen_moving' : 'static';
    }
    
    this.lastFrameTime = now;
  }
  
  getConfig(): StreamStateConfig {
    return STATE_CONFIGS[this.currentState];
  }
}
```

#### 2.3 Sharp 图像压缩 (src/browser.ts)

```typescript
import sharp from 'sharp';

async processFrame(
  data: string, // base64
  config: StreamStateConfig
): Promise<string> {
  const buffer = Buffer.from(data, 'base64');
  
  let processed: sharp.Sharp = sharp(buffer);
  
  if (config.format === 'jpeg') {
    processed = processed.jpeg({ quality: config.quality });
  } else {
    processed = processed.webp({ quality: config.quality });
  }
  
  const output = await processed.toBuffer();
  return output.toString('base64');
}
```

#### 2.4 FPS 控制

```typescript
class FrameRateController {
  private lastSentTime: number = 0;
  
  shouldSendFrame(fps: number): boolean {
    const now = Date.now();
    const minInterval = 1000 / fps;
    
    if (now - this.lastSentTime >= minInterval) {
      this.lastSentTime = now;
      return true;
    }
    return false;
  }
}
```

#### 3.3 Message Bridge 客户端 (src/message-bridge.ts)

```typescript
export class MessageBridge {
  private baseUrl: string;
  
  constructor(baseUrl?: string) {
    this.baseUrl = baseUrl || process.env.MESSAGE_BRIDGE_URL || 'http://192.168.0.4:8000';
  }
  
  async push(question: string, sessionId?: string): Promise<string> {
    const response = await fetch(`${this.baseUrl}/push`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ 
        question, 
        session_id: sessionId 
      }),
    });
    
    const { id } = await response.json();
    return id;
  }
  
  async pull(msgId: string): Promise<string> {
    const response = await fetch(`${this.baseUrl}/pull/${msgId}`);
    const { answer } = await response.json();
    return answer;
  }
  
  async ask(question: string, sessionId?: string): Promise<string> {
    const id = await this.push(question, sessionId);
    return await this.pull(id);
  }
}
```

#### 3.4 命令执行 (src/actions.ts)

```typescript

  const bridge = new MessageBridge();
  const answer = await bridge.ask(command.question);
  return {
    id: command.id,
    success: true,
    answer,
  };
}
```

### Phase 4: 前端交互页面

#### 4.1 页面功能

1. **实时画面显示**
   - 通过 WebSocket 接收 frame 消息
   - 显示 base64 编码的图像
   - 支持缩放适应窗口

2. **输入事件转发**
   - 鼠标移动、点击、滚轮
   - 键盘输入、快捷键
   - 坐标转换（屏幕坐标 → 页面坐标）

3. **状态栏**
   - 当前 URL
   - 标签页列表
   - 连接状态
   - 当前画质状态

#### 4.2 页面存储方式

使用内嵌 HTML 字符串，存储在 `src/viewer-html.ts`。

## 使用示例

### 示例 1: 获取远程 URL

```bash
# 启动时启用流媒体
AGENT_BROWSER_STREAM_PORT=9223 agent-browser open "https://example.com"

# 获取远程 URL
agent-browser viewer
# 输出: 
# URL: http://localhost:9223/view
# WebSocket: ws://localhost:9223
```

### 示例 2: 遇到验证码时询问用户

```bash
# 自动化脚本中
agent-browser open "https://example.com/login"
agent-browser fill '#username' 'user@example.com'
agent-browser fill '#password' 'password123'
agent-browser click '#submit'

# 检测到验证码，询问用户
if agent-browser is visible '#captcha'; then
  agent-browser ask "Please solve the captcha in the browser window (http://localhost:9223/view)"
fi

# 继续自动化
agent-browser click '#continue'
```

### 示例 3: 结构化问卷

```bash
# 发送结构化问题
agent-browser ask '{"questions":[{"header":"配送方式","question":"请选择配送方式：","multiSelect":false,"options":[{"label":"顺丰快递","description":"1-2天送达"},{"label":"普通快递","description":"3-5天送达"}]}]}'
```
