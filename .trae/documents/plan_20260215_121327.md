## 方案 A：完善 TypeScript CLI

### 文件结构
```
src/
├── cli.ts              # 入口点，主逻辑
├── cli/
│   ├── flags.ts        # 标志解析系统
│   ├── connection.ts   # Daemon 连接管理（增强版）
│   ├── commands.ts     # 命令解析
│   ├── output.ts       # 输出格式化
│   └── help.ts         # 帮助系统
```

### 实现内容

1. **flags.ts** - 全局标志解析
   - 所有 Rust CLI 支持的标志
   - 环境变量回退
   - 区分 CLI 传入和环境变量

2. **connection.ts** - 进程管理增强
   - `isDaemonReady()` - 检查 socket 可连接
   - `ensureDaemonRunning()` - 竞态条件处理
   - `sendCommandWithRetry()` - 重试机制

3. **commands.ts** - 命令解析
   - 保留现有命令
   - 新增 `install` 命令
   - 新增 `session` 命令

4. **help.ts** - 帮助系统
   - 每个命令的详细帮助

5. **output.ts** - 输出格式化
   - JSON 模式
   - 彩色输出

6. **更新 daemon.ts** - 进程管理修复

7. **重构 cli.ts** - 使用新模块
