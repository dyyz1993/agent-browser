## 问题分析

跨域 iframe 的 `snapshot --in-frame` 返回主页面内容而不是 iframe 内容。

**根本原因**：
- `getFrameByPath()` 使用 `frame.$(selector)` 和 `elementHandle.contentFrame()` 获取 Frame 对象
- 对于跨域 iframe，Playwright 的 `ariaSnapshot()` 可能无法正确获取 iframe 内容
- 需要使用 `frameLocator()` 链式方法来正确访问跨域 iframe

## 修复计划

### 1. 修改 `snapshot.ts` 中的 `getEnhancedSnapshot()` 函数
- 添加对 Frame 对象的特殊处理
- 对于跨域 iframe，使用 `frame.content()` 或其他方法获取内容
- 或者使用 `frameLocator()` 方式重新实现

### 2. 修改 `browser.ts` 中的 `getFrameByPath()` 方法
- 添加调试日志确认 Frame 对象是否正确获取
- 检查跨域 iframe 的 Frame 是否被正确识别

### 3. 更新跨域 iframe 测试用例
- 确保测试能正确验证跨域 iframe 的 snapshot

## 实现步骤

1. **调试确认问题**：在 `getFrameByPath()` 中添加日志，确认返回的 Frame 对象是否正确
2. **修复 snapshot 逻辑**：对于 Frame 对象，使用正确的方法获取 ARIA snapshot
3. **运行测试验证**：确保跨域 iframe 测试通过
4. **测试阿里云登录**：修复后进行阿里云登录流程测试
