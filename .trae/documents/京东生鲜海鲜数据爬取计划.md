# 京东生鲜海鲜数据爬取计划

## 目标
爬取京东生鲜海鲜商品数据，包括：
- 标题
- 店铺
- 价格
- 销量
- 好评数
- 中评数
- 差评数
- 地区

## 连接信息
- CDP: `ws://localhost:8080/client`
- 必须使用 `--human` 模拟人的行为

## 执行步骤

### 阶段1：初始化和验证登录状态

#### 1.1 连接到浏览器
```bash
node dist/cli.js --cdp ws://localhost:8080/client
```

#### 1.2 检查当前页面状态
```bash
# 获取当前URL
node dist/cli.js --cdp ws://localhost:8080/client get url

# 查看所有标签页
node dist/cli.js --cdp ws://localhost:8080/client tab list
```

#### 1.3 验证是否已登录
- 检查页面顶部是否有用户信息显示
- **禁止**直接打开登录地址
- 如果未登录，通过页面上的登录按钮进入

#### 1.4 检查弹窗
```bash
# 获取快照检查是否有弹窗
node dist/cli.js --cdp ws://localhost:8080/client snapshot -i
```

### 阶段2：搜索生鲜海鲜商品

#### 2.1 导航到搜索页面
```bash
node dist/cli.js --cdp ws://localhost:8080/client open "https://search.jd.com/Search?keyword=生鲜海鲜"
```

#### 2.2 模拟人类行为
```bash
# 随机鼠标移动模拟人类行为
node dist/cli.js --cdp ws://localhost:8080/client mouse wander 1000 --human
```

#### 2.3 等待页面加载完成
```bash
node dist/cli.js --cdp ws://localhost:8080/client wait --load networkidle
```

#### 2.4 检查验证码
- 获取页面快照
- 如果发现验证码，**立即停止**
- 通知用户处理验证码

#### 2.5 检查弹窗遮挡
```bash
node dist/cli.js --cdp ws://localhost:8080/client snapshot -i
```
- 如果有弹窗，先关闭弹窗
- 使用 `find` 命令查找关闭按钮

### 阶段3：采集商品列表数据

#### 3.1 获取商品列表快照
```bash
node dist/cli.js --cdp ws://localhost:8080/client snapshot -i
```

#### 3.2 定位商品元素
```bash
# 使用 find 命令查找商品列表容器
node dist/cli.js --cdp ws://localhost:8080/client find role listbox
```

#### 3.3 采集每个商品的基本信息
对于每个商品：
1. 使用 `get text` 获取标题
2. 使用 `get text` 获取店铺名
3. 使用 `get text` 获取价格
4. 使用 `get text` 获取销量

#### 3.4 滚动加载更多商品
```bash
node dist/cli.js --cdp ws://localhost:8080/client scroll down 500
node dist/cli.js --cdp ws://localhost:8080/client wait 2000
```

#### 3.5 保存商品列表数据
- 将采集的商品信息保存到临时文件
- 包含：标题、店铺、价格、销量、商品链接

### 阶段4：进入商品详情页采集评价

#### 4.1 点击第一个商品
```bash
# 使用 find 命令找到商品链接
node dist/cli.js --cdp ws://localhost:8080/client find role link click --name [商品标题]
```

#### 4.2 等待详情页加载
```bash
node dist/cli.js --cdp ws://localhost:8080/client wait --load networkidle
```

#### 4.3 检查是否打开新标签页
```bash
node dist/cli.js --cdp ws://localhost:8080/client tab list
```
- 如果是新标签页，切换到新标签页

#### 4.4 查找评价区域
```bash
node dist/cli.js --cdp ws://localhost:8080/client find role button click --name "评价"
# 或使用 text 查找
node dist/cli.js --cdp ws://localhost:8080/client find text "评价" click
```

#### 4.5 采集评价数据
- 查找好评数
- 查找中评数
- 查找差评数
- 使用 `get text` 命令获取数据

#### 4.6 查找地区信息
```bash
# 查找发货地区
node dist/cli.js --cdp ws://localhost:8080/client find text "发货地"
node dist/cli.js --cdp ws://localhost:8080/client get text [发货地元素]
```

#### 4.7 返回商品列表
```bash
# 方式1：使用 back 命令
node dist/cli.js --cdp ws://localhost:8080/client back

# 方式2：切换回原标签页
node dist/cli.js --cdp ws://localhost:8080/client tab switch 0
```

### 阶段5：循环采集更多商品

重复阶段4，采集多个商品的完整数据：
1. 点击下一个商品
2. 进入详情页
3. 采集评价数据
4. 返回列表
5. 继续下一个

### 阶段6：数据验证和保存

#### 6.1 验证数据完整性
- 检查每个商品是否包含所有必需字段
- 标题、店铺、价格、销量、好评、中评、差评、地区

#### 6.2 保存为JSON格式
```json
{
  "keyword": "生鲜海鲜",
  "crawl_time": "2025-02-24",
  "products": [
    {
      "title": "商品标题",
      "shop": "店铺名",
      "price": "价格",
      "sales": "销量",
      "good_reviews": "好评数",
      "neutral_reviews": "中评数",
      "bad_reviews": "差评数",
      "region": "地区"
    }
  ]
}
```

## 重要限制和注意事项

### 1. 命令使用规范
- ✅ 多用：`--help`, `find`, `get`
- ❌ 少用：`eval`
- 使用 `snapshot -i` 获取交互元素快照

### 2. 标签页管理
- 使用 `tab list` 查看所有标签页
- 使用 `tab switch <n>` 切换标签页
- 使用 `tab new` 创建新标签页
- 使用 `tab close <n>` 关闭标签页

### 3. 登录处理
- **禁止**直接打开登录地址
- 通过页面上的登录按钮进入
- 使用 `find` 命令查找登录按钮

### 4. 验证码处理
- 发现验证码立即停止
- 通知用户手动处理

### 5. 弹窗处理
- 每次操作前检查快照
- 查找并关闭弹窗
- 使用 `find` 命令查找关闭按钮

### 6. 模拟人类行为
- 使用 `mouse wander` 模拟随机鼠标移动
- 操作之间添加适当延迟
- 使用 `wait` 命令等待页面加载

## 数据采集策略

### 选择器策略
1. 首先使用 `snapshot -i` 查看页面结构
2. 使用 `find` 命令定位元素，而不是硬编码CSS选择器
3. 使用 `role` 和 `text` 定位器提高稳定性

### 错误处理
1. 每次操作后检查页面状态
2. 遇到弹窗先关闭
3. 遇到验证码停止并通知
4. 使用 `tab list` 监控标签页状态

### 性能优化
1. 合理设置等待时间
2. 批量采集商品列表后逐个采集详情
3. 避免不必要的页面刷新
