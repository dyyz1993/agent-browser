# 录制功能架构问题分析与重构计划

## 一、验证测试结果

### 测试1：addInitScript 行为

| 场景 | 结果 |
|------|------|
| 初始页面 | ✅ 自动执行 |
| 页面内链接跳转 | ✅ 自动执行 |
| 页面刷新 | ✅ 自动执行（新时间戳） |
| 新标签页（window.open） | ✅ 自动执行 |
| 新标签页（target="_blank"） | ✅ 自动执行 |
| 跨域导航 | ✅ 自动执行 |
| JavaScript 导航 | ✅ 自动执行 |
| 表单提交 | ✅ 自动执行 |

**结论**：`addInitScript` 在所有场景都会自动执行，**不需要额外的 `evaluate`**。

### 测试2：CDP Binding 行为

| 场景 | 结果 |
|------|------|
| 初始页面（导航前设置） | ❌ 导航后丢失 |
| 页面导航后（不重新设置） | ❌ 不可用 |
| 页面导航后（重新设置） | ✅ 可用 |
| 新标签页（不设置） | ❌ 不可用 |
| 新标签页（设置 CDP） | ✅ 可用 |
| 使用 load 事件自动设置 | ✅ 可用 |
| 使用 framenavigated 事件 | ✅ 可用 |

**结论**：**CDP Binding 需要在每次导航后重新设置**。

### 测试3：录制器实际问题

| 测试项 | 结果 |
|------|------|
| 初始面板存在 | ✅ |
| 导航后面板存在 | ✅ (addInitScript 自动创建) |
| 导航后 Binding 可用 | ❌ 丢失 |
| 步骤记录 | ✅ Node.js 端记录成功 |
| 页面端步骤同步 | ❌ 页面端 `__recorderSteps` 为空 |
| 新标签页面板 | ✅ 存在 |
| 新标签页 Binding | ❌ 不可用 |

**问题根源**：
1. `addInitScript` 执行时，CDP Binding 还未设置
2. inject.js 中的 `window.__recorderSync` 是 `undefined`
3. 步骤被记录到 Node.js 端，但无法同步到页面 UI

## 二、问题分析

### 问题1：时序问题

```
当前时序：
1. addInitScript 执行 inject.js
2. inject.js 检查 __recorderSync → undefined
3. 用户操作 → __syncStep() → __recorderSync() 失败
4. load/framenavigated 事件触发
5. setupBinding() 设置 CDP Binding
6. 但此时 inject.js 已经执行过了
```

**问题**：inject.js 执行时，binding 还没准备好。

### 问题2：步骤同步问题

```
当前流程：
1. 用户操作 → inject.js 捕获
2. __recorderSync() → CDP Binding
3. Node.js 收到 → this.recorderSteps.push()
4. page.evaluate() 同步到页面
5. 但页面可能已经导航，evaluate 失败
```

**问题**：页面导航后，`page.evaluate()` 可能失败，导致 UI 不同步。

### 问题3：新标签页问题

```
当前流程：
1. 新标签页打开
2. addInitScript 自动执行 inject.js
3. 但没有为新标签页创建 CDP session
4. __recorderSync 不可用
```

**问题**：新标签页没有 CDP Binding。

---

## 三、解决方案

### 方案A：轮询机制（推荐）

**原理**：页面端定期请求 Node.js 端同步步骤。

**优点**：
1. 不依赖 CDP Binding 的时序
2. 页面导航后自动恢复
3. 更可靠的同步机制

**实现**：

```javascript
// inject.js 中添加
let pollInterval = null;

function startPolling() {
  if (pollInterval) return;
  
  pollInterval = setInterval(() => {
    if (typeof window.__recorderSync === 'function') {
      window.__recorderSync(JSON.stringify({ action: '__poll__' }));
    }
  }, 500);
}

// 在 createRecorderOverlay 末尾调用
startPolling();
```

```typescript
// browser.ts 中处理轮询
this.recorderCdp.on('Runtime.bindingCalled', async (params: any) => {
  const payload = params.payload || '';
  
  try {
    const data = JSON.parse(payload);
    
    if (data.action === '__poll__') {
      // 轮询请求，只同步步骤
      await targetPage.evaluate((steps) => {
        window.__recorderSteps = steps;
        window.dispatchEvent(new CustomEvent('recorder:steps', { detail: steps }));
      }, this.recorderSteps).catch(() => {});
    } else if (data.action === '__clear__') {
      this.recorderSteps = [];
    } else {
      this.recorderSteps.push(data);
    }
  } catch (e) {}
});
```

### 方案B：延迟初始化

**原理**：在 inject.js 中等待 binding 可用。

```javascript
// inject.js 中
function waitForBinding(maxWait = 5000) {
  return new Promise((resolve) => {
    if (typeof window.__recorderSync === 'function') {
      resolve(true);
      return;
    }
    
    const startTime = Date.now();
    const check = setInterval(() => {
      if (typeof window.__recorderSync === 'function') {
        clearInterval(check);
        resolve(true);
      } else if (Date.now() - startTime > maxWait) {
        clearInterval(check);
        resolve(false);
      }
    }, 100);
  });
}

// 在需要同步时等待
window.__syncStep = async function(step) {
  const bindingReady = await waitForBinding();
  if (bindingReady) {
    window.__recorderSync(JSON.stringify(step));
  }
};
```

### 方案C：简化架构（最终方案）

**核心改动**：

1. **移除额外的 `evaluate`**：只使用 `addInitScript`
2. **在 inject.js 中添加轮询**：每 500ms 请求同步
3. **优化 CDP Binding 设置**：在 `load` 和 `framenavigated` 事件中设置
4. **存储所有 CDP sessions**：便于清理

## 四、具体修改

### 修改1：inject.js - 添加轮询机制

```javascript
// 在 createRecorderOverlay 函数末尾添加
let pollInterval = null;

function startPolling() {
  if (pollInterval) return;
  
  pollInterval = setInterval(() => {
    if (typeof window.__recorderSync === 'function') {
      window.__recorderSync(JSON.stringify({ action: '__poll__' }));
    }
  }, 500);
  
  // 页面卸载时清理
  window.addEventListener('beforeunload', () => {
    if (pollInterval) {
      clearInterval(pollInterval);
      pollInterval = null;
    }
  });
}

startPolling();
```

### 修改2：browser.ts - 处理轮询请求

```typescript
this.recorderCdp.on('Runtime.bindingCalled', async (params: any) => {
  const payload = params.payload || '';
  
  if (!payload) return;
  
  try {
    const step = JSON.parse(payload);
    
    if (step.action === '__poll__') {
      // 轮询请求，同步步骤到页面
      await targetPage.evaluate((steps) => {
        window.__recorderSteps = steps;
        window.dispatchEvent(new CustomEvent('recorder:steps', { detail: steps }));
      }, this.recorderSteps).catch(() => {});
    } else if (step.action === '__clear__') {
      this.recorderSteps = [];
    } else if (step.action !== '__update_step__') {
      this.recorderSteps.push(step);
    }
  } catch (e) {}
});
```

### 修改3：browser.ts - 移除多余的 evaluate

```typescript
// 之前
await page.context().addInitScript(injectScript);
await page.evaluate(injectScript);  // 删除这行

// 之后
await page.context().addInitScript(injectScript);
// 不需要额外的 evaluate
```

### 修改4：browser.ts - 存储 CDP sessions

```typescript
// 添加实例变量
private recorderCdps: Map<Page, CDPSession> = new Map();

// 在 setupBinding 中
const setupBinding = async (targetPage: Page) => {
  // 清理旧的 session
  const oldCdp = this.recorderCdps.get(targetPage);
  if (oldCdp) {
    try { await oldCdp.detach(); } catch {}
  }
  
  const cdp = await targetPage.context().newCDPSession(targetPage);
  await cdp.send('Runtime.addBinding', { name: '__recorderSync' });
  
  // 存储
  this.recorderCdps.set(targetPage, cdp);
  
  cdp.on('Runtime.bindingCalled', ...);
};

// 在 stopRecorder 中清理所有
for (const [page, cdp] of this.recorderCdps) {
  try { await cdp.detach(); } catch {}
}
this.recorderCdps.clear();
```
