# 录制功能优化计划

## 问题分析

### 问题1：步骤列表不显示在面板上 ✅ 已定位

**根本原因**：`__updateRecorderUI` 函数中的逻辑错误！

```javascript
// 问题代码（第732-737行）
container.innerHTML = steps.slice(-20).map((step, index) => {
  const action = step.action || 'unknown';
  const selector = step.selector || '';
  const value = step.value || '';
  const stepIndex = steps.length - 20 + index;  // ← 问题在这里！
  if (stepIndex < 0) return '';  // ← 当步骤数 < 20 时，所有 stepIndex 都是负数！
  // ...
}).join('');
```

**计算示例**：
- 假设 `steps.length = 2`
- `steps.slice(-20)` 返回这 2 个步骤
- 对于 index = 0: `stepIndex = 2 - 20 + 0 = -18 < 0`，返回 `''`
- 对于 index = 1: `stepIndex = 2 - 20 + 1 = -17 < 0`，返回 `''`
- 结果：所有步骤都被跳过，`container.innerHTML` 为空！

**修复方案**：
```javascript
// 修复后的代码
const displaySteps = steps.slice(-20);
const startIndex = Math.max(0, steps.length - 20);

container.innerHTML = displaySteps.map((step, index) => {
  const action = step.action || 'unknown';
  const selector = step.selector || '';
  const value = step.value || '';
  const stepIndex = startIndex + index;  // ← 正确计算
  // ...
}).join('');
```
