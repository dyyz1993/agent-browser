### 具体测试场景

#### 1. iframe-nested.html（3层嵌套iframe）
```html
<!-- 第1层 -->
<iframe id="frame1" srcdoc="
  <!-- 第2层 -->
  <iframe id='frame2' srcdoc=\"
    <!-- 第3层 -->
    <iframe id='frame3' srcdoc='
      <button id=\"deep-btn\" onclick=\"this.textContent=\\\"Clicked!\\\"\">Deep Button</button>
    '></iframe>
  \"></iframe>
"></iframe>
```

测试：
- `frame #frame1` -> `frame #frame2` -> `frame #frame3` -> `click #deep-btn`
- 验证深层iframe中的元素点击

#### 2. form-complex.html（复杂表单）
```html
<form id="test-form">
  <input type="text" id="username" placeholder="Username">
  <input type="email" id="email" placeholder="Email">
  <input type="password" id="password">
  <select id="country">
    <option value="us">US</option>
    <option value="cn">CN</option>
  </select>
  <input type="checkbox" id="agree">
  <input type="radio" name="gender" value="male">
  <input type="radio" name="gender" value="female">
  <textarea id="bio"></textarea>
  <button type="submit" id="submit-btn">Submit</button>
</form>
```

测试：
- `fill #username testuser`
- `select #country cn`
- `check #agree`
- 验证表单值

#### 3. drag-drop.html（拖拽测试）
```html
<div id="source" draggable="true">Drag Me</div>
<div id="target">Drop Here</div>
<script>
  target.addEventListener('dragover', e => e.preventDefault());
  target.addEventListener('drop', e => {
    e.preventDefault();
    target.textContent = 'Dropped!';
  });
</script>
```

测试：
- `drag #source #target`
- 验证拖拽结果

#### 4. dynamic-content.html（动态内容）
```html
<div id="container"></div>
<button id="add-btn" onclick="
  const div = document.createElement('div');
  div.className = 'dynamic-item';
  div.textContent = 'Item ' + document.querySelectorAll('.dynamic-item').length;
  container.appendChild(div);
">Add Item</button>
```

测试：
- `click #add-btn` -> `wait .dynamic-item` -> `get count .dynamic-item`

#### 5. scroll-area.html（滚动测试）
```html
<div id="scroll-container" style="height:200px; overflow-y:scroll;">
  <div style="height:1000px;">
    <button id="top-btn" style="margin-top:0;">Top</button>
    <button id="middle-btn" style="margin-top:400px;">Middle</button>
    <button id="bottom-btn" style="margin-top:800px;">Bottom</button>
  </div>
</div>
```

测试：
- `scrollintoview #bottom-btn`
- 验证滚动位置

#### 6. visibility-toggle.html（显示/隐藏测试）
```html
<button id="toggle-btn" onclick="
  const target = document.getElementById('toggle-target');
  target.style.display = target.style.display === 'none' ? 'block' : 'none';
">Toggle</button>
<div id="toggle-target" style="display:none;">Hidden Content</div>
```

测试：
- `is visible #toggle-target` -> false
- `click #toggle-btn` -> `is visible #toggle-target` -> true

### 测试示例（iframe.e2e.test.ts）
```typescript
describe('iframe nested (E2E)', () => {
  let browser: BrowserManager;

  beforeAll(async () => {
    browser = new BrowserManager();
    await browser.launch({ headless: true });
  });

  afterAll(async () => {
    await browser.close();
  });

  it('should click button in 3-level nested iframe', async () => {
    // 打开测试页面
    const openResult = await executeCommand(browser, 
      parseCliArgs(['open', getFixturePath('iframe-nested.html')]));
    expect(openResult.success).toBe(true);

    // 进入第1层iframe
    const frame1Result = await executeCommand(browser, 
      parseCliArgs(['frame', '#frame1']));
    expect(frame1Result.success).toBe(true);

    // 进入第2层iframe
    const frame2Result = await executeCommand(browser, 
      parseCliArgs(['frame', '#frame2']));
    expect(frame2Result.success).toBe(true);

    // 进入第3层iframe
    const frame3Result = await executeCommand(browser, 
      parseCliArgs(['frame', '#frame3']));
    expect(frame3Result.success).toBe(true);

    // 点击深层按钮
    const clickResult = await executeCommand(browser, 
      parseCliArgs(['click', '#deep-btn']));
    expect(clickResult.success).toBe(true);

    // 验证按钮文本改变
    const textResult = await executeCommand(browser, 
      parseCliArgs(['get', 'text', '#deep-btn']));
    expect(textResult.success).toBe(true);
    expect(textResult.data).toBe('Clicked!');
  });
});
```
