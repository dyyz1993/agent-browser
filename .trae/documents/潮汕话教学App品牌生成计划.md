### 3. 域名探测

**目标**: 检查生成的域名是否已被注册

**实现方案**:
- 使用 `whois` 命令检查域名注册状态
- 使用 `dig` 或 `nslookup` 检查域名解析
- 使用 `curl` 检查网站是否可访问

**判断逻辑**:
```
域名被注册的条件：
1. whois 查询返回注册信息
2. dig/nslookup 返回 DNS 记录
3. curl 能访问到网站内容

域名可用的条件：
1. whois 返回未注册
2. DNS 无记录
3. 无法访问
```

**技术实现**:
```bash
# 检查域名注册状态
check_domain() {
    local domain="$1"
    
    # 方法1: whois 检查
    if whois "$domain" 2>/dev/null | grep -q "No match"; then
        echo "AVAILABLE: $domain (whois)"
        return 0
    fi
    
    # 方法2: DNS 检查
    if ! dig +short "$domain" &>/dev/null; then
        echo "AVAILABLE: $domain (dns)"
        return 0
    fi
    
    # 方法3: HTTP 检查
    if ! curl -sI "https://$domain" --connect-timeout 5 | grep -q "HTTP"; then
        echo "MAYBE AVAILABLE: $domain (http)"
        return 0
    fi
    
    echo "TAKEN: $domain"
    return 1
}
```
