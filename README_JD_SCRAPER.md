# 京东"生鲜海鲜"商品数据爬取工具

基于 agent-browser 的自动化数据抓取工具，通过 CDP 连接浏览器获取京东商品数据。

## 功能特性

- 自动化搜索结果页面数据抓取
- 提取商品标题、店铺、价格、销量信息
- 支持滚动加载更多商品
- 数据验证和质量统计
- 生成 JSON 和 CSV 格式输出
- 日志记录和错误重试机制
- 可选的评论数据抓取

## 系统要求

- agent-browser CLI 工具
- 运行中的 CDP 浏览器服务 (ws://localhost:8080/client)
- jq (JSON 处理工具)
- bash shell

## 安装依赖

```bash
# 确保 agent-browser 已安装
npm install -g agent-browser

# 确保 jq 已安装 (macOS)
brew install jq

# 启动 CDP 浏览器服务（如果未运行）
# 根据你的环境配置启动方式
```

## 使用方法

### 1. 基础数据抓取

抓取京东"生鲜海鲜"商品的基本信息：

```bash
./scrape_jd_products.sh
```

输出文件：
- JSON: `/tmp/jd_products/products_TIMESTAMP.json`
- CSV: `/tmp/jd_products/products_TIMESTAMP.csv`
- 日志: `/tmp/jd_products/scrape_TIMESTAMP.log`

### 2. 抓取评论数据

从商品详情页抓取评论数据（好评、中评、差评）：

```bash
./scrape_jd_comments.sh <json文件> [商品数量]
```

示例：

```bash
# 获取前5个商品的评论
./scrape_jd_comments.sh /tmp/jd_products/products_20260224_150038.json 5

# 获取前10个商品的评论（默认）
./scrape_jd_comments.sh /tmp/jd_products/products_20260224_150038.json
```

### 3. 自定义配置

编辑 `scrape_jd_products.sh` 修改配置：

```bash
# CDP 连接地址
CDP_URL="ws://localhost:8080/client"

# 搜索关键词
KEYWORD="生鲜海鲜"

# 输出目录
OUTPUT_DIR="/tmp/jd_products"

# 最大滚动次数
MAX_SCROLLS=10
```

## 页面数据与XHR响应验证

### 搜索结果数据

京东搜索结果页面通过 JavaScript 动态加载商品数据，主要数据来源：

1. **DOM 元素提取**（当前方案）
   - 选择器: `[data-sku]`
   - 标题: `._text_1g56m_31`
   - 价格: `._price_d0rf6_14`
   - 店铺: `._name_b6zo3_45 span`
   - 销量: `._goods_volume_1xkku_1 span`

2. **API 接口**（可选方案）
   - 接口: `https://api.m.jd.com/api?functionId=pc_search_searchWare`
   - 需要参数: keyword, page, area 等
   - 受反爬限制影响

### 评论数据

评论数据主要来源：

1. **商品详情页 DOM**（当前方案）
   - 进入每个商品详情页
   - 提取评论摘要信息
   - 好评/中评/差评比例

2. **评论 API**（可选方案）
   - 接口: `https://club.jd.com/comment/productCommentSummaries.action`
   - 参数: referenceIds (SKU列表)
   - 容易受到"系统繁忙"或反爬限制

### 数据一致性验证

两种方案的数据结构对比如下：

| 数据来源 | 优点 | 缺点 |
|----------|------|------|
| DOM 提取 | 稳定可靠，模拟真实用户行为 | 速度较慢，需要页面加载 |
| API 接口 | 速度快，数据结构清晰 | 容易被反爬限制 |

## 抓取策略建议

### 小规模抓取（< 1000商品）
- 使用 DOM 提取方案
- 每次抓取间隔 1-2 秒
- 无需处理反爬限制

### 中等规模抓取（1000-10000商品）
- 结合 DOM 和 API 方案
- 优先使用 API，失败时降级到 DOM
- 增加重试和延迟机制

### 大规模抓取（> 10000商品）
- 考虑使用代理IP池
- 实现分布式抓取
- 遵守 robots.txt 和网站使用条款

## 错误处理

脚本包含以下错误处理机制：

1. **重试机制**: 失败操作自动重试3次
2. **日志记录**: 详细记录操作日志便于调试
3. **数据验证**: 验证数据完整性和质量
4. **优雅降级**: 评论API失败时继续抓取基础数据

## 常见问题

### Q: CDP 连接失败
A: 确保浏览器服务正在运行，检查 `ws://localhost:8080/client` 是否可访问

### Q: 评论API返回"系统繁忙"
A: 这是京东的反爬限制，可以：
- 使用详情页DOM提取方案
- 增加请求间隔时间
- 使用代理IP

### Q: 商品数量少
A: 尝试：
- 增加滚动次数（修改脚本中的 MAX_SCROLLS）
- 检查页面是否完全加载
- 手动滚动验证是否还有更多商品

### Q: 数据不完整
A: 检查：
- 页面选择器是否改变（京东可能更新页面结构）
- 查看日志文件定位具体问题
- 验证页面加载是否完成

## 性能优化建议

1. **并行抓取**: 对评论数据可以并行抓取多个商品
2. **缓存机制**: 避免重复抓取相同商品
3. **增量更新**: 只抓取新增或更新的商品
4. **请求合并**: 批量获取评论数据减少API调用

## 注意事项

1. **遵守法律法规**: 仅用于个人学习和研究目的
2. **尊重网站服务**: 不要频繁请求，避免给服务器造成压力
3. **数据使用**: 抓取的数据不得用于商业用途
4. **隐私保护**: 不要抓取用户个人信息
